## Overview

Natours lets users browse tours with maps and reviews, book them and pay by card. The backend follows MVC.

## Key features

- RBAC with user, guide, lead guide and admin roles
- Google login, sessions with access and refresh tokens
- Duplicate booking and duplicate review prevention

## Security

Bcrypt password hashing, JWT authentication, secure cookies, rate limiting, XSS and NoSQL injection protection, and file upload validation.
